## Step 1: Scaffolding (Vite + TS)

```bash
# Create Vite app (Select React, then TypeScript)
npm create vite@latest speech-therapy-app -- --template react-ts
cd speech-therapy-app

# Install Tailwind CSS (The styling engine)
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# Install The Core Stack (Router + Query)
npm install @tanstack/react-router @tanstack/react-query
npm install -D @tanstack/router-devtools @tanstack/react-query-devtools
```

## **Step 3: The "Gold Standard" Setup Files**

**A. Configure the Query Client (`src/main.tsx`)** This sets up the caching engine for the whole app.

TypeScript

```ts
import React from 'react'
import ReactDOM from 'react-dom/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { RouterProvider, createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen' // Auto-generated by TanStack Router
import './index.css'

// 1. Create the Query Client
const queryClient = new QueryClient()

// 2. Create the Router
const router = createRouter({ routeTree })

// 3. Register for type safety
declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <RouterProvider router={router} />
    </QueryClientProvider>
  </React.StrictMode>,
)
```

**B. Create Your First Route (`src/routes/__root.tsx`)** This is your "Layout" file. It stays persistent while pages change.

TypeScript

```ts
import { createRootRoute, Link, Outlet } from '@tanstack/react-router'
import { TanStackRouterDevtools } from '@tanstack/router-devtools'

export const Route = createRootRoute({
  component: () => (
    <>
      <div className="p-2 flex gap-2">
        <Link to="/" className="[&.active]:font-bold">
          Home
        </Link>
        <Link to="/therapy" className="[&.active]:font-bold">
          Therapy Session
        </Link>
      </div>
      <hr />
      {/* Renders the child route (the actual page content) */}
      <Outlet />
      {/* Debug tools - remove in production */}
      <TanStackRouterDevtools />
    </>
  ),
})
```
